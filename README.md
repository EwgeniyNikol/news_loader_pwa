## Описание

Приложение для загрузки новостей с поддержкой оффлайн-режима. Использует Service Workers для кэширования статических ресурсов.

## Технологии

- Webpack
- Koa.js
- Service Workers (Workbox)
- GitHub Actions
- Render

## Установка

```bash
npm install
Сборка
bash
npm run build
Запуск сервера
bash
npm start
